# 🪑 Woody State – Furniture E-Commerce Website

A full-stack furniture e-commerce website developed during my internship, featuring an aesthetically designed frontend, database-driven product management, customer interactions, and an administrative dashboard.

## 🚀 Project Overview

Woody State is a furniture shopping platform showcasing a variety of products, including beds, sofas, stools, lamps, and other home furnishings. The website provides customers with an interactive browsing experience while allowing administrators to manage products, monitor orders and oversee customer activity.

I led the project team and contributed to developing the website's frontend, backend functionality, database integration, and administrative features.

## ✨ Key Features

- **Admin Dashboard:** Centralized dashboard providing an overview of website activity.
- **Product Management:** CRUD operations to add, view, update, and delete products.
- **Order Management:** Admin functionality to view and monitor customer orders.
- **User Management:** Maintains registered users' information, including usernames and email addresses.
- **Customer Feedback:** Stores and displays customer reviews and messages.
- **Product Listing:** Dynamic display of furniture products.
- **Database Integration:** MySQL database to manage products, users, orders, reviews, and customer messages.
- **Interactive Frontend:** Visually appealing interface with aesthetic styling and smooth navigation.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Development Environment:** XAMPP

## ⚙️ How to Run Locally

1. Install and launch XAMPP.
2. Start Apache and MySQL.
3. Place the project folder inside the `htdocs` directory.
4. Open phpMyAdmin and create the required database.
5. Import the provided `.sql` database file.
6. Configure the database connection in the PHP configuration file.
7. Open your browser and navigate to:

   `http://localhost/your-project-folder/`
